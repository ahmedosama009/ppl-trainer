# خطة التدريب — Push / Pull / Legs

أداة تمرين بالعربي: بتعرض الجلسة الحالية تمرين تمرين بصورتين (البداية والنهاية)،
بتسجّل الوزن والعدات والمجموعات، وبتحسب التدرّج لوحدها.

## الفكرة

مفيش ارتباط بأيام الأسبوع. الجلسات طابور من ٨:

```
Push A → Pull A → Legs A → فترات + سونا → Push B → Pull B → Legs B → استشفاء + سونا
```

تخلّص الجلسة أو تتخطّاها → اللي بعدها تبقى الحالية، وتتسجّل بتاريخ اليوم اللي عملتها فيه.
لما الـ ٨ يخلصوا، الأسبوع بيزيد لوحده (١ → ٦) وبعدين ميزو جديد.

## اللي بتعمله

- **٦٦ تمرين** كل واحد بصورتين للحركة ونقط أداء مكتوبة
- **تدرّج مزدوج أوتوماتيك** — كمّلت أعلى المدى في كل المجموعات؟ بيقولك زوّد كام وارجع لكام عدة،
  بالزيادة الصح لكل نوع (٥ كجم للسكوات، ٢.٥ للبنش، ١–٢.٥ للعزل)
- **تدرّج الحجم** — +١ مجموعة كل أسبوع لحد ٥، وأسبوع ٦ تخفيف ٥٠٪ لوحده
- **مؤقت راحة** بيشتغل أول ما تخلّص مجموعة
- **متابعة** — حجم أسبوعي لكل عضلة مقابل المستهدف، تقدّم كل تمرين، الوزن ومحيط الوسط، اختبار ٢٠٠٠م
- **مرجع** — التسخين، التغذية، الكارديو، علامات الحمل الزايد، ملاحظات الكتف، جدول القياس

## البيانات

كل حاجة متخزّنة في `localStorage` على الجهاز — مفيش سيرفر ومفيش حساب.
مفيش بيانات شخصية جوه الكود: أرقامك (الوزن، نسبة الدهون، الماكروز) بتكتبها مرة
في **المرجع ← بياناتي** وبتفضل على جهازك.

المزامنة بين الأجهزة مش موجودة — استخدم **تصدير/استيراد** لو غيّرت موبايل.

## التطوير

```
python3 build.py
```

بيبني حاجتين من `src/`:

| المخرج | الاستخدام |
|---|---|
| `التمرين.html` | ملف واحد مستقل — يتفتح من غير سيرفر |
| `docs/` | نسخة الويب (GitHub Pages) — PWA بتشتغل أوفلاين بعد أول فتح |

`src/img-data.js` فيه ١٣٢ صورة WebP مستخرجة من ملف الخطة الأصلي (PDF) ومضغوطة.
